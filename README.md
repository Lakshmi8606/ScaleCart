\# ScaleCart 



A production-grade e-commerce microservices backend built with Java 17, 

Spring Boot 3.x, PostgreSQL, Redis, Kafka, and Docker.



\## Services

\- \*\*auth-service\*\* — JWT + RSA authentication

\- \*\*com-service\*\* — Product catalog with Redis caching

\- \*\*order-service\*\* — Order management with Kafka events

\- \*\*payment-service\*\* — Payment flow with webhook handling

\- \*\*notification-service\*\* — Async notifications via Kafka consumer

\- \*\*report-service\*\* — PDF invoice generation with JasperReports



\## Tech Stack

Java 17 | Spring Boot 3.x | PostgreSQL | Redis | Kafka | 

RabbitMQ | Docker | Jenkins | AWS EC2
